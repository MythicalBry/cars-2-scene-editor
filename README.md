# Cars 2 Scene Editor

A Blender add-on for editing Cars 2: The Video Game worlds: the scene tree, geometry, materials and textures,
lights, light rigs and probes, baked lighting, collision, Meridian choreographies, triggers and locators, and
actor properties.

**Install:** download `cars2_scene_editor.zip` from the
[Releases](../../releases) page, then in Blender: Edit > Preferences > Add-ons > Install from Disk, pick the zip
and enable **Cars 2 Scene Editor**. The tools are in 3D View > Sidebar (N) > Cars 2 Scene.

Tested to work on Blender 4.5.9 LTS and later (also 5.x). Blender 4.1 does not work.

The full manual is [cars2_scene_editor/README.md](cars2_scene_editor/README.md); technical notes are in
[cars2_scene_editor/docs](cars2_scene_editor/docs).

This repository contains no game files. You need your own copy of the game. Cars 2 and its game files
belong to their respective owners.
